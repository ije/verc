# Verc

A media player with a modern UI for macOS, powered by VLC.

## Development

Requires Xcode 26+ and the Metal Toolchain on an Apple silicon Mac.

```sh
./scripts/build.sh
open dist/Verc.app
```

Use `--debug` for a debug build.
