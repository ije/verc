# Verc

A native media player for Apple silicon and macOS 26+. SwiftUI, AppKit, SF Symbols, and the VLC playback engine.

Verc takes its visual cues from [Vercel](https://vercel.com/home): sparse layouts, monochrome controls, fine borders, and clear typography. [VLC](https://github.com/videolan/vlc) supplies the playback engine.
